# 🩸 Shared Vitality (Кровная связь)

Мод для Minecraft **26.2 (Fabric)**, объединяющий игроков отряда в единую систему выживания.

---

## 🌟 Ключевые механики

* **Единый пул здоровья (Bloodlink Pool)**:
  * Все игроки команды делят один виртуальный запас HP.
  * Урон, полученный любым союзником, вычитается из общего запаса и зеркалируется без зацикливания урона.
  * Если общий пул падает до нуля — погибает вся команда!
* **Механика дистанции (Tether System)**:
  * До 64 блоков: обычный режим.
  * 64–128 блоков: натяжение уз (янтарная индикация).
  * \>128 блоков: разрыв уз (голод и слабость).
  * Разные измерения: сжигает 1 HP общего пула раз в 5 секунд.
* **10 уникальных ролей**:
  * 🛡 **Страж (Guardian)**
  * 🧪 **Алхимик / Повар (Apothecary)**
  * ⛏ **Геолог (Delver)**
  * 🏹 **Следопыт (Scout)**
  * ⚔ **Жнец / Берсерк (Reaper)**
  * 📖 **Зачарователь / Мистик (Enchanter)**
  * 🧱 **Строитель / Архитектор (Mason)**
  * 🐺 **Зверолов / Пастух (Beastmaster)**
  * 🗡 **Тень / Ассасин (Shadow)**
  * 👻 **Шаман / Врачеватель (Soulbinder)**
* **Старт игры**:
  * Игроки заходят на сервер в режим ожидания.
  * Администратор пишет `/startad`, после чего каждому участнику случайно и без повторов выдается роль, и игра начинается!
* **Предмет «Кровавый бинт»**: крафтится из слизи и нитей, восстанавливает здоровье в общий пул.
