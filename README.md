## 🌟 Описание

Shared Vitality (Кровная связь) — мод для Fabric (Minecraft 26.2), который объединяет игроков в команду с общим пулом здоровья и механикой «тета» (связи по расстоянию). Мод делает выживание более командным: нужна координация, планирование ролей и внимательное отношение к товарищам.

---

## ✨ Что добавляет мод

- 🩺 Общий пул здоровья: уроны распределяются по общему ресурсу команды.
- 🔗 Тетивная система: расстояние между игроками влияет на состояние команды (предупреждения, дебаффы).
- 🧭 Роли: уникальные классы с бонусами и ограничениями.
- 🩹 Предмет «Кровавый бинт»: лечит общий пул и стимулирует командный обмен ресурсами.
- 🎛 Настраиваемые параметры сервера (опции на стороне сервера): гибкость правил для разных форматов игры.

## 🧩 Роли (коротко)

- 🛡 Guardian — щит команды, повышает выживаемость.
- 🧪 Apothecary — поддержка, усиливает восстановление и готовит бинты.
- ⛏ Delver — добыча и исследование, бонусы при работе с ресурсами.
- 🏹 Scout — разведчик с повышенной мобильностью.
- ⚔ Reaper — дамагор, наносит больше урона.
- 📖 Enchanter — усиливает экипировку и баффы.
- 🧱 Mason — строитель и защитник позиций.
- 🐺 Beastmaster — взаимодействие с существами и питомцами.
- 🗡 Shadow — стелс и внезапные атаки.
- 👻 Soulbinder — лечит команду и управляет риском.

(Подробные описания ролей доступны в игре или на странице мода.)

## 🚀 Как играть (быстрый старт)

1. Установите Fabric Loader, совместимый с Minecraft 26.2.
2. Установите Fabric API (если требуется).
3. Скачайте последний релиз мода и поместите файл `.jar` в папку `mods` вашего инстанса.
4. Запустите Minecraft с Fabric и зайдите на сервер/в мир с модом.
5. Начните матч — команда автоматически получает роли и общий пул.

---

## 🎮 Советы для игроков

- Держитесь ближе 64 блоков: это безопасная зона.
- Кооперируйтесь: предметы лечения и ресурсы должны распределяться согласно ролям.
- Не уходите в другие измерения в одиночку: связь ослабнет и начнёт сжигать общий пул.
- Следите за индикацией тетива — мод даёт визуальные и звуковые подсказки о состоянии связи.
